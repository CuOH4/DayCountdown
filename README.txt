DayCountdown
============

C# / WPF 桌面倒计时应用 —— 无主界面，每个倒计时都是一张可独立拖动、缩放、置顶的现代深色小卡片。

【简介】
DayCountdown 把每个倒计时做成一张"小卡片"悬浮在桌面上，你可以同时开多个倒计时互不干扰，位置、大小、置顶状态、备注、目标日期全部自动保存，下次启动原样恢复。关闭卡片不会丢记录，随时可在设置中重新打开。

- 自包含单文件 exe，约 133 MB，免安装 .NET、拷贝即用，内存占用低
- 深色现代 UI，自定义图标与统一风格的确认/提醒对话框
- 配置自动持久化，关闭不丢失

【功能特性】
- 多倒计时并存：无主界面，每个倒计时一个独立卡片窗口
- 卡片随意摆：拖拽移动、8 方向边缘缩放、双击空白恢复默认大小（320x180）
- 目标日期：双击卡片底部日期区域，或在右键菜单中"设置目标日期"，使用日期选择器修改；超过/到达目标日期自动切换显示文案
- 备注命名：双击标题文字或右键"重命名备注"
- 置顶显示：点卡片上的图钉按钮，或右键菜单勾选"窗口置顶"
- 一键整理：右键"整理到右上角"，自动避让已有卡片从上到下排布
- 背景透明度：设置中拖动滑块实时预览（5% ~ 100%），全局生效并保存
- 开机自启：设置中一键开关（写入注册表 HKCU Run）
- 关闭即隐藏：关闭卡片只隐藏记录，不删除；所有卡片关闭前会弹统一风格的退出提醒
- 多窗口/单实例：重复启动只会聚焦已有实例，不会开新进程

【快速开始】

一、直接运行
双击 publish\DayCountdown.exe 即可。本版本为自包含发布，已内置 .NET 10 
首次启动会自动创建一张默认倒计时卡片（默认目标为 7 天后）。

二、源码构建
环境要求：Windows + .NET 10 SDK
命令：dotnet build -c Release

三、从源码发布（自包含单文件 exe）
项目已内置发布配置（SelfContained / PublishSingleFile），只需：
命令：dotnet publish -c Release -r win-x64 -o publish
输出为 publish\DayCountdown.exe（单个文件，约 133 MB，含运行时，拷贝到任何 Win10/11 64 位电脑即可运行）。



【使用说明】
操作              方式
------------------------------------------
移动卡片          按住卡片空白处拖动
缩放卡片          拖拽卡片四边 / 四角
恢复默认大小      双击卡片空白处（标题文字除外）
修改目标日期      双击底部日期区域，或右键 -> 设置目标日期
重命名备注        双击标题文字，或右键 -> 重命名备注
置顶 / 取消置顶   点标题右侧图钉按钮，或右键菜单
新建倒计时        右键 -> 新建倒计时
一键避让整理      右键 -> 整理到右上角
隐藏卡片（保留记录） 右键 -> 关闭
删除记录          右键 -> 删除，或在设置中删除
打开设置          右键 -> 设置

关闭 vs 删除：关闭 = 隐藏卡片但保留记录（可在设置中重新打开）；删除 = 连同记录一起移除，不可恢复。

【数据存储】
配置文件位置：%AppData%\DayCountdown\config.json
内容包含所有倒计时记录（名称、目标日期、位置、大小、置顶、是否隐藏）以及全局设置（开机自启、卡片透明度），JSON 明文、UTF-8 中文直接可读。删除该文件即恢复出厂状态。
旧版单目标配置文件会被自动迁移兼容。

【技术栈】
- .NET 10 (net10.0-windows)，WPF
- 单实例互斥锁、注册表自启、JSON 配置持久化
- 无第三方依赖，纯框架实现
